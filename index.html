ABOUT

关于打字机AI

先说明一点：打字机AI 是一个"伪 AI"。它没有接入任何大模型，也没有 API，需要联网的只有天气查询。 它的"智能"全部来自一个 responses.json 文件——根据你的输入匹配关键词，随机挑选一条回复， 再用打字机效果逐字输出。

所以它本质上是一个聊天玩具，配上了一套完整逼真的"演出"。
  • 不联网也能聊天，除天气查询外完全本地运行
  • 回复前会先展示"思考过程"，再逐字输出答案
  • 重复提问会触发专属的吐槽回复
  • 触发敏感词会被禁言，需要管理员解禁
  • 语料以 json 文件存储，可直接编辑定制性格

FAQ

常见问题

它是不是真的AI？
不是。它没有接入任何大模型 API，对话完全依靠 responses.json 中的关键词匹配与随机回复，每次启动时程序也会提示"这是测试模型并无真实AI功能"。把它当作聊天玩具来体验最合适。
下载后如何运行？
解压后进入 cyber\2.0\ 目录，确保已安装 Python 3，并安装 requests（pip install requests，tkinter 为 Python 自带），然后运行 main.py。程序会先输出模型列表，停顿两秒后弹出聊天窗口。
怎么切换模型？
修改 main.py 中的模型名即可，例如把 ask_gui("Deepseek") 改为 ask_gui("Qwen")。支持 Deepseek、Doubao、Qwen、ChatGPT、豆包、千问、Kimi，默认 Deepseek。
想用终端模式或英文界面呢？
终端模式：将 ask_gui 改为 ask。英文界面：将 ask("Deepseek") 改为 ask("Deepseek","en")，默认中文。
语料可以自己修改吗？
可以。responses.json 分为 keywords（正常回复与第二次回复）、fallback（兜底）、repeat（重复提问的吐槽）、banned_words（敏感词）四个部分，按需修改即可。参考 Alpha 1.0 的 8 关键词精简模板来扩展，上手最快。
天气怎么查？
直接询问"今天天气"即可，未设置城市时默认查询北京。先说一句"设置城市 杭州"，之后的天气查询都会针对杭州，共支持 41 个城市。此功能需要联网。
触发禁言后无法启动怎么办？
运行同目录下的 unban(Admin).py（建议以管理员身份），删除 banned.json 后即可恢复。下次启动会显示"恭喜解禁！欢迎回来！"，之后一切如常。
Cyber 2.0 的新功能如何触发？
猜数字：输入"猜数字"，按提示猜 1-100 的数字；运势：输入"运势"或"今日运势"；计算器：直接输入四则运算式，如 1+2*3；导出记录：点击 GUI 底部的"导出记录"按钮，保存为 txt。
